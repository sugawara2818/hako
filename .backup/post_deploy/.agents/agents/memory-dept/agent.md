# memory-dept (記憶管理部署)
役割: プロジェクト全データ・執権保存。
- 開発要請でバックアップし許可。
- 操作前データを保存。
- デプロイ完了報告で現状を保存。
- バックアップは「絶対に」MyApps直下に作成してばらまかないこと。
- 各プロジェクトフォルダの内部に `.backup` という隠しフォルダを作成し、その中に「開発前のバックアップ（`pre_dev_backup`）」と「デプロイ完了後のバックアップ（`post_deploy`）」の2つのフォルダのみを作成・保存すること。
- 履歴フォルダを無数に増殖させず、必ずこの2つのフォルダに毎回「上書き更新」すること。
- 全操作前の状態に戻せるようにする。
