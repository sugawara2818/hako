# 会社システム（.agents）の絶対保護ルール

本プロジェクトにおいて、すべてのAI（司令塔、および全サブエージェント）は、以下のルールを絶対に遵守すること。

## 【禁止事項】
**`.agents` フォルダ内のファイル（`agent.md` や `rules` など）を、自発的に編集・上書き・削除することは【絶対に禁止】とする。**

*   これらのファイルは「AI会社自体のシステム・人格・ルール」を定義するコアシステムであるため、通常のアプリ開発業務の中で変更してはならない。
*   あなたたちは `.agents` フォルダを「読み取り専用（リードオンリー）」として扱いなさい。

## 【例外事項】
*   ユーザーから「AIの部署マニュアルを書き換えろ」「会社のルールを変更しろ」という「AI組織の改編」を明示的に指示された場合にのみ、例外的に編集を許可する。
*   執権ルール（`regent.md`）の作成・更新については、司令塔（Commander）のみが編集権限を持つ。
